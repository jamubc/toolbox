# toolbox

Little tools for [Claude Code](https://claude.com/product/claude-code).
<br/>
<br/>
<br/>
<br/>
***Start by adding 'toolbox' to your claude marketplace ⤵***
```
/plugin marketplace add jamubc/toolbox
```
---

| Plugin | Install | What it is |
| --- | --- | --- |
| [redline](plugins/redline/README.md) | `/plugin install redline@toolbox` | A tachometer for your Claude sessions: why use many claude when few claude do trick. |
| [channel](plugins/channel/README.md) | `/plugin install channel@toolbox` | Your chats in a pane beside Claude Code: read, reply, and get a toast when someone messages you. iMessage today, more chat apps to come. |
| [instantnotes](plugins/instantnotes/README.md) | `/plugin install instantnotes@toolbox` | Your InstantNotes in a pane beside Claude Code: search, read a note as Markdown, and capture a new one with /note. |
| [browse](plugins/browse/README.md) | `/plugin install browse@toolbox` | Adds /browse: a web browser in a pane beside Claude Code. |
| [atlas](plugins/atlas/README.md) | `/plugin install atlas@toolbox` | Adds /atlas: a file explorer in a pane beside Claude Code. Open a file to edit it in micro. |

Requires Claude Code 2.1.287 or later. MIT licensed.
